# Productivity

Teaching and learning workspace for building durable skills through missions,
lessons, reference docs, and learning records.

## What it does

Helps the agent act as a tutor inside the current workspace, grounded in the
user's real-world goals and prior learning.

| Area | Examples |
|------|----------|
| Missions | Capture why the user wants to learn a topic |
| Lessons | Build short, interactive HTML lessons tied to the mission |
| Reference | Cheat sheets, glossaries, syntax, and reusable assets |
| Tracking | Learning records that capture progress and misconceptions |
| Communities | Find high-signal groups where the user can test their skills |

## Skills

### `teach`

Activated when the user asks to learn something, wants a lesson, or wants to be
taught a skill or concept. Creates a stateful teaching workspace with
`MISSION.md`, `RESOURCES.md`, lessons, learning records, and reference documents.
Includes format guides for missions, resources, learning records, and glossaries.
